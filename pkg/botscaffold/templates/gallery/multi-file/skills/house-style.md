# House style

Replace this with your team's conventions. A skill is knowledge the
agent reads on demand — keep it factual and grounded in real files.

- Match the repository's existing structure and naming before inventing
  any; when two conventions coexist, follow the one the nearest file uses.
- Every claim about the code is grounded in a file you opened in this
  run, never in what the code "should" do.
- Commit in small, semantic units (`type(scope): imperative summary`).
- Report honestly: what was done, what was verified, what remains.
